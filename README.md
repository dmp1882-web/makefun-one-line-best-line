# One Line, Best Line

make.fun bounty `u-gudril-cool-one-line-best-line-b8c41f4d` (program/v1).

A single scroll-stopping joke line: a smart fridge breaks up with its owner, landing on a chill pun.

## Entry

```
My smart fridge just sent me a breakup email: it says I'm the reason it keeps running, and it can't chill with me anymore.
```

## Program

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). It is deterministic: the same bytes on every run.
